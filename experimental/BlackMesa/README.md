## Related libraries:

- Microsoft Agent Framework / Orleans — useful for agent-based simulations, but they're more distributed-agent
  infrastructure than a Mesa clone.
- MASON — excellent agent-based simulation framework, but Java, not C#.
- ABM.NET / Agent-Based Modeling libraries — there are several smaller .NET projects, but the ecosystem is much thinner
  than Python's Mesa ecosystem.
- Math.NET Numerics — excellent for the Monte Carlo / numerical mathematics side, but not an agent-based simulation
  framework.
- ScottPlot — useful for visualizing simulation results, not simulation itself.
- Accord.NET — older but contains statistics, machine learning, optimization, and some simulation-related functionality.
